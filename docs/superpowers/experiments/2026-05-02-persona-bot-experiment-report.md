# Persona-Bot 실험 보고서 (2026-05-02)

## 1. 실험 배경 및 목적
인공지능 모델이 단순히 다른 말투를 사용하는 것을 넘어, 독립적인 가치관과 기억을 가진 '인격체'로서 동작할 수 있는지 검증한다. 특히 한국적 맥락이 반영된 데이터셋(NVIDIA Nemotron-Personas-Korea)과 초경량 에이전트 프레임워크(nanobot)의 시너지를 확인한다.

## 2. 실험 환경
- **Framework:** nanobot (HKU Data Intelligence Lab)
- **Model:** qwen3:14b (Remote Ollama Server)
- **Dataset:** nvidia/Nemotron-Personas-Korea
- **Interface:** Terminal (CLI)

## 3. 실험 단계 및 결과

### [Phase 1] 초기 환경 구축 및 페르소나 주입
- **내용:** 김철수(50대 교사), 이영희(20대 개발자) 페르소나 설정 및 초기 답변 비교.
- **결과:** 말투와 정보 구성 방식에서 뚜렷한 차이 발생. 하지만 도구(Skill) 사용 로그는 모델의 높은 지능으로 인해 명확히 대조되지 않음.

### [Phase 2] 기억의 진화 검증
- **내용:** 각 에이전트에게 서로 다른 데이터(역사적 수치 vs 기술적 보고서)를 주입하고 동일한 질문에 대한 답변 변화 관찰.
- **결과:** **성공.** 특히 이영희 에이전트가 이전 대화의 기억을 바탕으로 '기술 기반 해결책'을 제시하며 인격의 진화를 보여줌.

### [Phase 3] 인격체 생성기 및 강제 몰입
- **내용:** NVIDIA 데이터셋에서 무작위 페르소나를 추출하여 nanobot 설정을 자동 생성하고 시연.
- **결과:** **성공.** 모델의 기본 정체성(Qwen)이 페르소나를 덮어쓰는 문제를 **'Identity Prefix(인격 마스킹)'** 기법으로 해결. 60세 경비원, 28세 연구원 등 입체적인 자아를 성공적으로 구현.

## 4. 기술적 통찰 (Lessons Learned)
1. **페르소나의 닻(Anchor):** 모델의 자기 인식이 강할수록 시스템 프롬프트(Preamble)만으로는 부족하며, 메시지 레벨에서의 지속적인 역할 부여가 필수적임.
2. **기억의 힘:** 독립된 세션과 메모리 저장소는 인격체 간의 상충하는 의견을 가능하게 하는 핵심 요소임.
3. **데이터셋 활용:** NVIDIA의 페르소나 데이터셋은 에이전트에게 '구체적인 삶의 배경'을 제공하는 아주 훌륭한 소스임.

## 5. 향후 과제
- 인격체 간의 다자간 토론(Multi-agent Debate) 환경 구축.
- 텔레그램/디스코드 연동을 통한 실시간 인격체 서비스 시연.
- 장기 기억(Long-term Memory)의 선택적 보존 및 성찰 루틴 구현.
